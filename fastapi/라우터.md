# FastAPI의 라우터(Router) 설명

## 1. 라우터란?

FastAPI의 라우터는 관련된 경로(path)들을 그룹화하고 구조화하는 방법을 제공합니다. 이를 통해 애플리케이션의 구조를 더 잘 조직화하고 관리할 수 있습니다.

## 2. 라우터의 주요 특징

- **경로 분리**: 관련된 엔드포인트들을 하나의 라우터로 그룹화할 수 있습니다.
- **코드 구조화**: 큰 애플리케이션을 여러 개의 작은 모듈로 나눌 수 있습니다.
- **재사용성**: 라우터를 다른 FastAPI 애플리케이션에서 재사용할 수 있습니다.
- **prefix 지원**: 라우터에 prefix를 설정하여 모든 경로에 공통 접두사를 추가할 수 있습니다.

## 3. 라우터 사용 방법

### 3.1 라우터 생성

```python
from fastapi import APIRouter

router = APIRouter()
```

### 3.2 라우터에 경로 추가

```python
@router.get("/items")
async def read_items():
    return {"items": ["Item 1", "Item 2"]}
```

### 3.3 메인 앱에 라우터 포함

```python
from fastapi import FastAPI

app = FastAPI()
app.include_router(router)
```

## 4. 라우터 고급 기능

### 4.1 prefix 설정

```python
router = APIRouter(prefix="/api/v1")
```

### 4.2 태그 설정

```python
router = APIRouter(tags=["items"])
```

### 4.3 의존성 추가

```python
router = APIRouter(dependencies=[Depends(verify_token)])
```

## 5. 라우터 사용의 장점

1. **모듈화**: 큰 애플리케이션을 작은 부분으로 나눌 수 있습니다.
2. **유지보수성**: 관련 기능을 함께 그룹화하여 코드를 더 쉽게 관리할 수 있습니다.
3. **확장성**: 새로운 기능을 쉽게 추가하거나 기존 기능을 수정할 수 있습니다.
4. **테스트 용이성**: 개별 라우터를 독립적으로 테스트할 수 있습니다.

## 6. 결론

FastAPI의 라우터는 대규모 애플리케이션을 효과적으로 구조화하고 관리하는 데 매우 유용한 도구입니다. 적절히 사용하면 코드의 가독성, 유지보수성, 그리고 재사용성을 크게 향상시킬 수 있습니다.
