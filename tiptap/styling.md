# Tiptap의 기본 텍스트 스타일링 기능

Tiptap은 **ProseMirror**를 기반으로 한 확장 가능한 텍스트 에디터로, 다양한 텍스트 스타일링 기능을 제공합니다. 다음은 Tiptap에서 제공하는 기본적인 텍스트 스타일링 기능입니다:

## 1. 기본 텍스트 스타일
Tiptap에서 제공하는 주요 텍스트 스타일링 옵션은 다음과 같습니다:
- **굵게 (Bold)**: `Bold` 확장을 사용하여 텍스트를 굵게 표시합니다.
- **기울임꼴 (Italic)**: `Italic` 확장으로 텍스트를 이탤릭체로 표시합니다.
- **밑줄 (Underline)**: `Underline` 확장으로 밑줄을 추가할 수 있습니다.
- **취소선 (Strike-through)**: `Strike` 확장을 사용하여 취소선을 적용할 수 있습니다.

## 2. 제목과 단락
- **제목 (Heading)**: 여러 단계의 제목(`<h1>`, `<h2>`, `<h3>` 등)을 설정할 수 있습니다.
- **단락 (Paragraph)**: 일반 텍스트 단락을 만들 수 있는 기본 `Paragraph` 확장이 제공됩니다.

## 3. 리스트 (목록)
- **순서 없는 목록 (Bullet list)**: 불릿 포인트로 목록을 작성할 수 있습니다.
- **순서 있는 목록 (Ordered list)**: 번호가 매겨진 목록을 작성할 수 있습니다.

## 4. 텍스트 정렬
추가 확장을 통해 텍스트를 좌, 우, 중앙, 혹은 양쪽 정렬로 배치할 수 있습니다.

## 5. 확장성과 사용자 정의
Tiptap은 모듈형 구조로, 필요한 기능을 쉽게 추가하거나 제거할 수 있습니다. 사용자 정의 확장을 통해 더 복잡한 스타일링이나 기능도 구현할 수 있습니다.
